# Calculator

A sleek desktop calculator built with **Flutter** and **Dart**.

This project started as a UI-focused Flutter project and gradually evolved into a functional calculator with custom interactions, keyboard input, calculation history, and adaptive number display.

> **Current platform:** macOS
> **Android support:** Planned for a later version

## ✨ Features

* Basic arithmetic operations
* Keyboard input support
* Calculation history
* Clear history
* Adaptive number display
* Scientific notation for very large/small values
* Hover and pressed button states
* Custom calculator UI
* Resizable desktop window
* Responsive keypad layout

## 🛠️ Built With

* **Flutter**
* **Dart**
* **window_manager** — desktop window sizing and controls

## 📁 Project Structure

```text
lib/
├── main.dart
├── calculator_button.dart
└── history.dart
```

The project is kept relatively simple, with separate files used for reusable or independent UI components.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* macOS with Xcode installed

### Run the project

Clone the repository:

```bash
git clone https://github.com/arya-ajith/flutter-calculator.git
```

Navigate into the project:

```bash
cd calculator
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run -d macos
```
